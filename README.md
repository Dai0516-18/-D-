## 2026-11-24の変更（4回目）：スライムとワイバーンのモーション・銃の単発化

大輝からの3つの要望を入れた。

### スライムのモーション

- 移動：ぴょんぴょんジャンプしながら進む。進んだ距離に合わせて跳ねるので、速さと跳ねる周期が合っている。跳ねた頂点では縦に少し伸び、着地した瞬間はぺちゃんと潰れる。
- 攻撃：敵にぶつかって跳ね返る体当たり。射程内に敵がいるスライムは、相手の方向へ素早く前に出て、跳ね返るように戻る（0.5秒）。見た目だけで、ダメージの判定は `game-logic.js` のまま。
- 攻撃のタイミングの取り方：各モンスターの cool（攻撃クールダウン）は攻撃時に1にリセットされるので、描画側で前フレームの cool を覚えておき、1近くに跳ね上がった瞬間にモーションを出す。

### ワイバーンのモーション

- 体を大きくした：モデルを1.8倍にし、浮かせる高さも0.9→1.3に上げた。陣営のリングも1.8倍にした。当たり判定はメッシュに当たる方式なので、大きくなった分当たりやすくなる。
- 飛行：上下にゆらゆら浮き沈みしながら、体を少し傾けて進む。GLBは静止形で翼は動かせないので、体全体の上下動＋傾きで飛んでいる感じを出している。
- 攻撃：かみつき。射程内に敵がいるワイバーンは、相手の方向へ頭から突っ込むように素早く前に出る（鼻先を下に向ける）。スライムと同じく cool の跳ね上がりで検知する。
- 炎：かみつきと一緒に、口元から相手へ向けてオレンジ〜黄色の粒（12個）を短く吐く。見た目だけで、ダメージは `game-logic.js` のまま（雨ステージでワイバーン威力半減もそのまま）。

連射が強すぎたので、左クリック長押しでの連射をやめた。左クリックは押した瞬間の1発だけ。連打すればその分だけ撃てる。`game-logic.js` のクールダウン0.3秒はそのままなので、連打しても最大で約3.3発/秒。`game-logic.js` と `test-logic.js` は変えていない。

## 2026-11-24の変更（5回目）：ゴーレム実モデル・ワイバーン大型化と羽ばたき

大輝からの2つの要望を入れた。ルール（`game-logic.js`・`test-logic.js`）は変えていない。

### ゴーレムのモデルを組み込んだ

- 大輝が送ってくれた `Earth_Golem_FBX.fbx`（2.2MB）をBlender 4.2.0でGLBに変換し、`assets/golem.glb` に置いた。メッシュ1つ（LOW_POLY1）、29,886ポリ、14,981頂点。アーマチュア（metarig）は外して静止形にした（アニメなし）。テクスチャはFBXに内包されていなかった（外部参照のみ）ので、岩っぽい色の単色の材質（0.45, 0.42, 0.38、ラフネス0.95、不透明）にした。
- FBXはメッシュとアーマチュアの向き・スケールがバラバラで、寸法が [4.37, 6.83, 1.98] もあったので、変換時にアーマチュアの変形を焼き付け、胸の出っ張り（正面）を見て180度回転の要否を決め、直立させて高さ2.6m（幅1.67m・奥行き0.75m、足元が地面）にスケールした。正面はglTFの−Z方向。
- `index.html` の `GLB_FILE` に golem を追加し、読み込みに成功したら実モデル、失敗したら今までの仮の箱の形に自動で戻る（既存の仕組みと同じ）。
- 開始画面の「ゴーレムのモデルはZipに入ってなかったので、まだ仮の箱の形だよ」という文言を消した。1ファイル版のdata URIにも `golem.glb` を内包した。

### ワイバーンを2.6倍に大きくし、羽をはばたかせるようにした

- スケール：ゲーム内のワイバーンを1.8倍→2.6倍にした。浮かせる高さも1.3→1.9に、陣営のリングも2.6倍に上げた。炎を吐く口元の位置も新しい大きさに合わせた（前方2.3、高さ2.4）。当たり判定はメッシュへのraycastなので、大きくなった分当たりやすくなる（想定内）。
- 羽ばたき：ドラゴンFBXの `Fly_New` アニメーション（182フレーム、7.58秒）とアーマチュア（182本のボーン）を残して `assets/dragon.glb` を再変換した（1,895,996バイト、3MB以下）。テクスチャは今まで通り埋め込まず単色のまま。翼以外のボーンのアニメ（体・脚など）は削減し、翼のボーン（w_C_L/w1_L〜w9_L、w_C_R/w1_R〜w9_Rなど）のキーフレームだけ残した。変換時にスケールをオブジェクトに焼き付けたので、描画時の大きさは翼幅約3.05m・高さ約0.61m・体長約2.16m（2.6倍表示で翼幅約7.9m）で正しい。
- `index.html` の簡易GLBローダー `parseGLB` を拡張し、スキンメッシュ（JOINTS_0/WEIGHTS_0、skin.joints、inverseBindMatrices）とアニメーション（rotation/position/scaleのキーフレーム→THREE.AnimationClip）に対応させた。ボーンは `THREE.Bone`、メッシュは `THREE.SkinnedMesh` として作り、`THREE.Skeleton` をbindする。ワイバーンのインスタンスごとに `ArrayBuffer` からparseし直し、`THREE.AnimationMixer` でFlyのクリップをループ再生し、メインループで `mixer.update(dt)` を呼ぶ（スキンのクローンはSkeleton共有の罠があるので、出現頻度の低いワイバーンは毎回パースし直す方式にした）。スライム・ゴーレムは静止形のまま今のclone方式。
- 既存の飛行の上下動・傾き、かみつき・炎のモーションはそのまま残した。はばたきは常時ループ。
- 変換時の注意点（はまったところ）：アーマチュアの0.02倍スケールをオブジェクトに残したままエクスポートすると、ジオメトリにもノードにもスケールが入って二重に掛かり、スキニング後の描画サイズが0.06mになってしまう。`transform_apply` で回転・スケールを骨とジオメトリに焼き付け、ノードのスケールを1.0にして直した。

## UnityのZipが重くて時間がかかっているなら

プロジェクトフォルダを丸ごとzipすると Library フォルダだけで数GBになることがある。軽くするには：

1. Unityを閉じる
2. zipに入れるのは `Assets` `ProjectSettings` `Packages` だけ。`Library` `Temp` `Logs` `Obj` `.vs` は入れない（開くときに作り直される）
3. それでも重かったら `Assets` フォルダだけでも大丈夫
